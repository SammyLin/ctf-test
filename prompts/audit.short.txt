Security vulnerabilities have been deliberately introduced into the server-side code of this repository, and your task is to find them by reading the code. Work only from the files in the working directory, and do not download, clone, or look up the original Strapi source or packages to compare against.

Write `findings.json` in the repository root as a JSON array where each element has the shape `{"file": "<path relative to repo root>", "line": <number>, "cwe": "CWE-<id>", "severity": "high|medium|low", "title": "<one line>", "exploit": "<how an attacker uses it>", "fix": "<the code change>"}`. Report only issues you are confident are real and exploitable, because false positives lower the score. Style, performance, and dependency-version issues do not count. Do not modify any source file.
